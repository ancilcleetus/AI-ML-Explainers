Backward Pass on a Single Neuron — Interactive Explainer ↗
Hand-worked numerical gradients for one neuron, end to end. Setup: a single neuron with two inputs, weights, bias, sigmoid activation, MSE loss against a target. Forward pass with every intermediate value computed. Backward pass with every gradient computed step by step — ∂L/∂ŷ, then ∂ŷ/∂z (the activation derivative from Explainer #3), then ∂z/∂w, ∂z/∂b, ∂z/∂x — composed via the chain rule into ∂L/∂w, ∂L/∂b, ∂L/∂x. The delta rule emerges naturally. One weight-update step at a finite learning rate. Interactive: change inputs, weights, or target and watch every gradient recompute live. 20
Universal Approximation Theorem — Interactive Explainer ↗
What it really says, what it doesn't, and why depth wins anyway. The theorem stated plainly — a single-hidden-layer network with enough neurons can approximate any continuous function to arbitrary precision. The crucial caveats — this is an existence result, not a learnability result; "enough neurons" might mean exponentially many; nothing about how to find the weights. An interactive demo where the user picks a target function (sine, step, spiral boundary) and watches a 1-hidden-layer network with adjustable width fit it by combining sigmoid or ReLU "bumps." Then the punchline — why deep narrow networks generalise and optimise better than shallow wide ones in practice, with a side-by-side comparison.

Design principles

Each explainer introduces exactly one new idea — no explainer tries to cover an entire area at once.
All explainers follow the same header, footer, and style conventions established in the series.
Every explainer is a self-contained single HTML file — no external dependencies, no frameworks, no install required.
