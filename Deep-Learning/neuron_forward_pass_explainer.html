What is a neuron?

Before going into the mechanics, let us frame what we are about to learn.

The big picture

A neural network is a function. You give it some input (an image, a sentence, a row of numbers), and it produces some output (a prediction, a classification, a generated word). Inside, the network is built from one repeating unit — the neuron.

One neuron does one small thing: it takes a few input numbers, combines them in a specific way, and produces one output number. Stack many neurons in layers, and you get a network that can solve image recognition, machine translation, protein folding, and more.

The pattern of this roadmap: understand the neuron first → then stack neurons into layers → then train the stack with data. This explainer covers the first step. Every later explainer assumes you understand it.
Three things a single neuron has
1. Inputs
A few numbers coming in. In a real network these are either raw data (pixel values, word embeddings) or outputs from neurons in the previous layer.
2. Weights & bias (learnable parameters)
One weight per input — these decide how much each input matters. One extra number called the bias. The weights and bias are what the network learns during training.
3. An activation function
A non-linear function applied at the end — without it, every neuron would just compute a straight line, no matter how many you stack. The Activation Functions Explainer covers why this matters.

Put these three together and the neuron computes a single output number. That is everything. The rest of this explainer shows you exactly how — visually, interactively, and in code.

Biological vs. artificial neuron

The artificial neuron is loosely inspired by biology. Dendrites → inputs, synaptic strength → weights, cell body → weighted sum + activation, axon → output.

What this neuron actually computes

A neuron with two inputs is computing a straight line across the input space. Inputs on one side of the line make the neuron output a high value (the neuron fires); inputs on the other side make it output a low value. The weights and bias are exactly the numbers that decide where this line sits.

The mathematics, very briefly

With two inputs, the weighted sum is z = w₁·x₁ + w₂·x₂ + b. The boundary where the neuron switches between "fire" and "don't fire" is where z = 0 — which rearranges to x₂ = −(w₁/w₂)·x₁ − b/w₂. That is the equation of a straight line. Every single neuron in a network is, geometrically, just a line (or hyperplane in higher dimensions).

The limitation — one neuron cannot solve XOR

Consider four points arranged in a square: (0,0) and (1,1) should output 0, while (0,1) and (1,0) should output 1. This is the classic XOR problem. Try as you might — there is no single straight line that separates the green from the red points below.

One neuron can only draw one straight line. That is its hard limit. To solve XOR — or recognise faces, translate languages, or beat humans at Go — you need many neurons stacked into layers. That is what the Tensors Explainer sets up next — and what the rest of the roadmap explores.

Key equations & code

Weighted sum
z = w₁x₁ + w₂x₂ + … + wₙxₙ + b = Σᵢ(wᵢ · xᵢ) + b
Each input multiplied by its weight, summed, then shifted by the bias.
ReLU activation
a = max(0, z)
Returns z if positive, 0 otherwise. Most widely used in deep networks. See the Activation Functions Explainer for a deep dive.
Sigmoid activation
a = 1 / (1 + e⁻ᶻ)
Squashes output to (0, 1). Used in binary classification output layers.
Tanh activation
a = (eᶻ − e⁻ᶻ) / (eᶻ + e⁻ᶻ)
Squashes output to (−1, 1). Zero-centred — often preferred over sigmoid in hidden layers.
In code — building this neuron in PyTorch
# A single neuron with 3 inputs and 1 output, followed by ReLU.
# nn.Linear(3, 1) creates the weights (w₁, w₂, w₃) and bias b for you.
import torch
import torch.nn as nn

neuron = nn.Sequential(
    nn.Linear(3, 1),  # 3 inputs → 1 output (the weighted sum z)
    nn.ReLU()        # the activation function
)

# Use it on some input — exactly the example from the sliders
x = torch.tensor([[1.5, -2.0, 0.8]])
y = neuron(x)        # y is the output a = f(z)
That is it — three lines of code build a real, working neuron. A full neural network is just nn.Linear stacked with more activations in between. The Tensors Explainer shows how this scales up to layers of many neurons at once.
Intuition: Think of weights as "importance dials" and the bias as a "default activation level" that lets the neuron fire even when all inputs are zero.
