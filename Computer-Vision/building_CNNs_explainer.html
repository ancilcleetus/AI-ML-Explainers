Stacking convolutions — the core idea

Each convolutional layer receives the output of the previous layer as its input. The first layer sees raw pixels and detects simple patterns. Subsequent layers detect combinations of those patterns, building increasingly abstract representations.

Feature hierarchy
1
First layer — edges & corners
Filters learn to detect oriented edges, colour blobs, and simple textures — the raw building blocks of all visual information.
Low-level
2
Second layer — textures & shapes
Combinations of edges form corners, curves, and texture patterns. The network begins to represent shapes and object parts.
Mid-level
3
Third layer — object parts
Textures combine into recognisable parts: wheels, eyes, fur, windows. The receptive field (the region of the original image that this neuron can "see") now spans a significant region of the image — it grows with each successive layer.
High-level
N
Final layers — entire objects
Parts assemble into complete semantic concepts: "cat," "car," "aeroplane." These representations feed into the classifier head.
Semantic
The idea is beautifully simple: each layer captures progressively higher-level features by operating on the output of the previous layer, not the raw pixels. The depth of the network determines the abstraction level it can reach.

Between conv layers — ReLU & max pooling

Between convolution layers, two operations are typically applied: ReLU activation and max pooling. Together they introduce nonlinearity and spatial compression.

ReLU simply sets all negative values to zero: f(x) = max(0, x). This introduces non-linearity, allowing the network to learn complex patterns. Without it, stacking convolution layers would collapse into a single linear operation.

ReLU(x) = max(0, x)
Any negative activation is clamped to zero. Positive activations pass through unchanged. The gradient is 1 for positive inputs, 0 for negative — no vanishing gradient for active neurons.
ReLU is the most widely used activation in CNNs. It is computationally free (just a threshold), avoids the vanishing gradient problem (where gradients shrink to near-zero as they travel back through many layers, making early layers learn extremely slowly) for positive inputs, and produces sparse activations (most neurons output zero — only the most relevant ones fire — which makes computation faster and prevents overfitting).

Max pooling shrinks the spatial dimensions by keeping only the maximum value in each local region. A 2×2 max pool with stride 2 halves the height and width, reducing computation while retaining the strongest features.

MaxPool(i,j) = max( O(2i,2j), O(2i+1,2j), O(2i,2j+1), O(2i+1,2j+1) )
For each 2×2 non-overlapping block: take the largest value and discard the rest. Spatial size halves; the most prominent activation in each region survives.
Max pooling achieves translation invariance (robustness to small shifts — the same feature is detected whether it appears one or two pixels to the left or right): a feature detected one or two pixels to the left still produces the same maximum. This robustness is crucial for recognising objects at varying positions.

The full CNN pipeline

An image flows through several blocks of Conv + ReLU + Pool. Spatial dimensions shrink as the number of feature channels grows. Finally, features are flattened and passed to a fully connected classifier.

A tensor is simply a multi-dimensional array of numbers — the data structure that flows through every layer of a neural network. For an image it has three dimensions: height × width × channels (colour bands).

A minimal CNN in PyTorch

Here is a concrete implementation following the conv + ReLU + pool pattern. Three convolutional blocks progressively increase the channel depth while halving the spatial size, followed by a fully connected classifier.

import torch import torch.nn as nn class SimpleCNN(nn.Module): def __init__(self, num_classes=10): super().__init__() self.features = nn.Sequential( # Block 1: 3 → 32 channels, spatial size halved nn.Conv2d(3, 32, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2), # Block 2: 32 → 64 channels, spatial size halved again nn.Conv2d(32, 64, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2), # Block 3: 64 → 128 channels, spatial size halved again nn.Conv2d(64, 128, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2), ) self.classifier = nn.Sequential( nn.Flatten(), nn.Linear(128 * 4 * 4, 256), nn.ReLU(), nn.Linear(256, num_classes), ) def forward(self, x): x = self.features(x) x = self.classifier(x) return x

Landmark CNN architectures

This architecture follows the lineage of landmark models that advanced the state of the art by going deeper — but they all relied on the same fundamental operation: the convolution.

What is ImageNet? ImageNet is a benchmark dataset of 1.2 million photographs across 1,000 categories (cats, cars, aircraft, and 997 more). From 2010–2017 it was the standard competition for measuring visual recognition — winning it became the most influential signal that a new architecture actually worked.

Skip connections
Each model advanced the state of the art by going deeper. ResNet introduced skip connections — shortcuts that feed the input of a block directly to its output, bypassing the layers in between. This gives gradients a clear path backwards and means early layers always receive a useful learning signal, solving the vanishing gradient problem and making networks of 100+ layers trainable for the first time.

The limitation of locality

If CNNs are so powerful, why do we need anything else? The answer lies in a fundamental limitation: the receptive field problem. Each convolution filter only looks at a small local neighbourhood — typically 3×3 or 5×5 pixels.

1
Information must travel through many layers
A relationship between a bird in the top-left corner and the water in the bottom-right corner requires the signal to propagate through dozens of layers of convolution before they can "communicate."
2
More layers means more cost
Stacking more layers to expand the receptive field requires more parameters, more computation, and more memory. It also introduces vanishing gradients, which make training difficult.
3
Long-range dependencies are learned indirectly
The network must learn to route information through many intermediate representations. This is inefficient and unreliable — CNNs struggle with tasks that require understanding global scene context.
What if a network could look at the entire image at once — where every part of the image could directly communicate with every other part in a single operation? This is precisely the idea behind the Vision Transformer.
