The magnifying glass intuition

A 2D convolution takes an input image I and a small filter (also called a kernel) K of size k×k, and computes an output feature map O. At each position (i, j), it computes a weighted sum of the pixel values in the local neighbourhood under the filter.

How it works: Position the filter over a small patch of the image. Multiply each filter number by the pixel directly beneath it. Add all those results together — that single sum is one output value. Slide to the next position and repeat.
O(i, j) = Σm Σn I(i+m, j+n) · K(m, n)
For each output position (i,j): overlay the k×k filter, multiply each filter value by the pixel beneath it, then sum all products. That sum is a single output value.
This looks intimidating, but it is simply a weighted sum of the pixel values in a local neighbourhood. The filter defines which pixels matter and how much — positive weights amplify, zero weights ignore, negative weights invert.

Input image I
The grid of pixel values the filter slides across — e.g. our 4×4 pixel grid in the next section
Filter / kernel K
The small k×k weight matrix — learnable during training — e.g. our 3×3 number grid in the next section

The key insight — filters are learnable

The hand-crafted filters above were designed by humans who understood what edges look like. Real CNNs do something more powerful: they learn what to detect automatically from data.

The filter values are not fixed. During training, the neural network discovers which local patterns are important by adjusting the filter weights to minimise the loss. Early layers tend to learn simple patterns like edges and corners. Deeper layers learn more complex patterns like textures, object parts, and eventually entire objects.

Output size — how big is the feature map?

When you apply a k×k filter to an n×n image with stride s and padding p, the output feature map size is determined by a simple formula.

Output size = ⌊(n + 2p − k) / s⌋ + 1
n = input size, k = filter size, p = padding, s = stride
Two important parameters — explained
Stride (s)
How many pixels the filter jumps at each step. Stride 1 = move one pixel at a time (dense, larger output). Stride 2 = skip every other position (faster, smaller output).
Padding (p)
Extra border of zeros added around the image before sliding. Padding 0 = filter never goes outside. Padding 1 = adds a ring of zeros so the filter can be centred on every edge pixel too.
